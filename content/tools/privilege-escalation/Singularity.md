## Description

Singularity is a Linux kernel rootkit targeting the Linux 6.x kernel series. It demonstrates advanced kernel-space stealth techniques, including hidden module loading, process and socket hiding, credential escalation to root, and out-of-band command-and-control triggered via crafted ICMP echo payloads.
