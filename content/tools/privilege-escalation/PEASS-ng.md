## Description

PEASS-ng (Privilege Escalation Awesome Scripts Suite) contains LinPEAS, WinPEAS, and MacPEAS. These tools search for possible privilege escalation vectors on Linux, Windows, and macOS systems, highlighting findings with color-coded severity.
