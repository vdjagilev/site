## Description

CycleTLS is an evasion and proxying library available for Go and JavaScript that allows outbound HTTP/HTTPS requests to spoof browser TLS client hellos, cipher suites, elliptic curves, and JA3/JA4 fingerprints. It allows network scanners and security tools to interact with targets protected by Cloudflare, Akamai, or DataDome without being blocked as automated scripts.
