## Description

Pangolin is an open-source, identity-centric remote access gateway built on WireGuard. It unifies reverse proxying and mesh VPN networking, providing browser-based access to internal web applications, VNC, RDP, and SSH sessions alongside secure tunnel transport for client-to-site connectivity without public port exposure.
