## Description

An advanced, yet simple, tunneling/pivoting tool that uses a TUN interface. Ligolo-ng establishes a lightweight TLS or TCP tunnel between a target machine (agent) and your attacking system (proxy), letting you route full subnets and run standard tools like Nmap without SOCKS proxychains bottlenecks.
