## Description

Chisel is a fast TCP/UDP tunnel written in Go that transports traffic over HTTP, secured via SSH. It includes both client and server in a single binary, providing reverse port forwarding, SOCKS5 proxying, and encrypted communications capable of bypassing restrictive egress firewalls.
