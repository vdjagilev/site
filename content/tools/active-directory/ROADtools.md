## Description

ROADtools is an exploration framework for Azure AD (now Microsoft Entra ID). It queries Microsoft Graph and Azure AD APIs to dump the entire tenant directory structure into a local SQLite database. This allows offline relational queries, interactive visualization through a built-in web GUI, and attack path discovery across users, service principals, conditional access policies, and enterprise applications.
