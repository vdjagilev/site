## Description

SMBMap allows users to enumerate samba share drives across an entire domain. Features include listing share drives, drive permissions, share contents, upload/download functionality, file name auto-download pattern matching, and remote command execution. Designed specifically for penetration testers to simplify searching for sensitive data across large networks.
