## Description

godap is a feature-rich terminal user interface (TUI) written in Go for inspecting and exploring LDAP directories, specifically targeting Active Directory environments. It enables security researchers and system administrators to navigate directory trees, search objects, inspect permissions and access control lists (ACLs), export data, and modify attributes directly from the command line without graphical management tools.
