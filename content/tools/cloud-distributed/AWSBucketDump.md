## Description

AWSBucketDump is a multi-threaded reconnaissance tool tailored for finding accessible Amazon Web Services S3 buckets. Similar to a subdomain bruteforcer, it iterates through permutations and keywords to identify public buckets, inspect access permissions, and filter or download sensitive assets and configuration dumps.
