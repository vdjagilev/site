## Description

AWSHound is a cloud security tool that discovers attack paths and privilege escalation opportunities across complex AWS environments. It extracts permissions and configurations from IAM, Organizations, S3, KMS, SSM, EC2, Lambda, and EKS, modeling cross-account relationships and effective access in an OpenGraph format for visual querying and graph-based analysis.
