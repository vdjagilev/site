## Description

ShadowClone allows security practitioners to distribute long-running tasks dynamically across thousands of serverless functions (such as AWS Lambda) and returns aggregated results within seconds for tasks that would otherwise take hours. It is particularly effective for large-scale port scans, HTTP probing, and content fuzzing.
