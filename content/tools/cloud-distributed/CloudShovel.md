## Description

CloudShovel is an AWS scanning tool designed to inspect Amazon Machine Images (AMIs) for leaked API tokens, private SSH keys, database credentials, and hardcoded secrets. It automates snapshot creation, volume mounting, and heuristic scanning based on large-scale public AMI security research.
