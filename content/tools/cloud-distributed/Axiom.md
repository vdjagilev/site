## Description

Axiom is an orchestration and dynamic fleet-management framework designed for cloud-native offensive security. It builds disposable server instances across cloud providers (DigitalOcean, AWS, Azure, Linode) preloaded with security tooling, and splits large reconnaissance workloads (nmap, ffuf, nuclei, masscan) across hundreds of instances simultaneously via `axiom-scan`.
