## Description

subsnipe is a fast subdomain takeover detection utility that audits target DNS CNAME records against signatures for dozens of third-party cloud services (such as GitHub Pages, AWS S3, Heroku, Shopify, and Fastly). It validates whether dangling DNS pointers can be registered by an unauthorized party.
