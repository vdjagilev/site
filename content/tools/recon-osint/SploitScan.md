## Description

SploitScan is a vulnerability assessment and triage utility. Given a CVE ID or target list, it queries authoritative security repositories to correlate CVSS metrics, EPSS (Exploit Prediction Scoring System) likelihood scores, CISA Known Exploited Vulnerabilities (KEV) inclusion, and public exploit proof-of-concepts to help defenders prioritize remediation.
