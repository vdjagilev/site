## Description

Interactsh is an open-source tool developed by ProjectDiscovery for detecting out-of-band interactions. It provides a full-featured interaction server and CLI/Burp client that logs and alerts on DNS, HTTP(S), SMTP(S), and LDAP requests, featuring automatic ACME wildcard TLS certificate generation and end-to-end payload encryption with zero persistent logging.
