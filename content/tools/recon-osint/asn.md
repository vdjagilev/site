## Description

asn is a terminal-based OSINT and network reconnaissance tool that aggregates BGP routing statistics, autonomous system numbers (ASNs), IPv4/IPv6 prefix allocations, RPKI validity states, and IP reputation data into a single unified view. It includes an interactive AS-path traceroute visualization and an embedded lookup API server.
