## Description

dnsrecon is a standard-setting DNS exploration tool written in Python. It executes comprehensive DNS auditing tasks, including zone transfer checks (AXFR), reverse lookup scans, subzone delegation mapping, SRV record discovery, wildcard domain resolution detection, and top-level domain enumeration.
