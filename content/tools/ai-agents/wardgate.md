## Description

Wardgate operates as a security control layer and policy proxy between AI agents and external environments. It provisions credential-isolated API proxies, runs policy-gated remote execution conclaves, applies sensitive data redaction to outgoing prompts, and enforces interactive approval workflows before agents execute sensitive tools.
