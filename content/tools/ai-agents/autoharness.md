## Description

autoharness is an autonomous skill layer and harness for agentic coding tools (such as Claude Code). It observes and analyzes developer interactions during real coding sessions, detects recurring problem-solving patterns and workflows, and synthesizes them into modular agent skills to continuously boost agent performance and task accuracy.
