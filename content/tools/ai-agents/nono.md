## Description

nono is a secure, kernel-enforced sandboxing CLI and SDK tailored for autonomous AI agents, MCP servers, and LLM coding tools (including Claude Code, OpenClaw, and OpenCode). It enforces fine-grained capability isolation, filesystem snapshotting with atomic rollbacks, secure credential masking, and cryptographic provenance trails for non-deterministic agent executions.
