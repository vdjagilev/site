## Description

RSigma is a Rust-native engine and intermediate representation for Sigma detection rules. Capable of evaluating over 1.1 million events per second, it features strongly-typed AST parsing, a Language Server Protocol (LSP) daemon, and Model Context Protocol (MCP) server integration for automated security engineering and threat detection pipelines.
