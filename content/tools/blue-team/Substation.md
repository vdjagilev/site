## Description

Substation is an open-source, cloud-native data processing toolkit developed by Brex. Written in Go, it routes, normalizes, and enriches high-volume security event logs (such as AWS CloudTrail, VPC Flow Logs, and endpoint telemetry) before they reach storage or SIEM analytical pipelines.
